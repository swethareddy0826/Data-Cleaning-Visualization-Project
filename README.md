# Data Cleaning & Visualization Project

## Objective
This project focuses on cleaning raw data, removing inconsistencies, handling missing values, and generating meaningful visual insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features
- Removed duplicate records
- Handled missing values
- Removed outliers
- Generated cleaned dataset
- Created visualization charts

## Output Files
- cleaned_data.csv
- summary_report.txt
- sales_chart.png

## Learning Outcome
Learned data preprocessing, visualization, and storytelling using Python.
